# JABAKHANJI STORE PS5
Separate PS5 portal for JABAKHANJI STORE.
Upstream: https://github.com/jordyidk/slopkit commit 6153152be0b6a69e7e7931ff1b68523b7fde1429
Supported firmware: 9.00, 9.05, 9.20, 9.40, 9.60, 10.00, 10.01, 10.20, 10.40, 10.60, 11.00, 11.20, 11.40, 11.60, 12.00
Future versions are display-only; no support or release date is promised.
Launch requires PS5 user agent, an exact supported firmware and a user click. Not hardware-tested.
